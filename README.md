# ltei-grupo-2 — CV de Jonathan MirCha

Por **Jonathan MirCha**.

## Descripción del proyecto

Este repositorio contiene mi currículum en forma de página web de una sola pantalla, además de su sistema de diseño.

La página principal presenta quién soy: desarrollador UX y de software, profesor universitario y creador de contenidos. Incluye mis secciones de inicio, sobre mí, educación, experiencia, habilidades, cursos y contacto.

La segunda página muestra las reglas visuales del proyecto (colores, letras, espacios y componentes) para que todo se vea ordenado, moderno y fácil de leer, con el color naranja como protagonista.

Todo está hecho sólo con HTML, CSS y JavaScript, sin programas complicados, para que cargue rápido y dure muchos años.
